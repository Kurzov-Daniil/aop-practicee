**Навіщо окремі типи?**

Цілі рахуються ідеально й швидко (в процесорі окремий блок), а дробові - з похибками за спеціальним стандартом, бо влаштовані зовсім інакше.

**Що таке рухома кома?**

Це коли кома «плаває» в залежності від степеня числа. Потрібна, щоб в один тип влізти і величезні числа, і мікроскопічні.

**Скільки цифр запам'ятовує?**

У float десь 7 значущих цифр, у double - близько 15–17.

**Чому 0.1 + 0.2 != 0.3?**

Бо комп'ютер у двійковій системі не може точно записати ці дроби, вони стають нескінченними, через що з'являється помилка (0.30000000000000004).

**Чому не для грошей?**

Через отакі мікропохибки на великих сумах і купі операцій гроші просто почнуть губитися чи не сходитися в балансі.

**Чи може число не дорівнювати собі?**

Так, спеціальне значення NaN (якщо поділити нуль на нуль). Воно не дорівнює навіть самому собі (NaN == NaN це false).
