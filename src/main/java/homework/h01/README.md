**git log** розв'язує задачу «хто, коли і навіщо вніс зміни», та відображає хронологічну історію комітів із даними авторів та їхніми коментарями.

**git diff** розв'язує задачу «що саме змінилося», та показує точну різницю між версіями файлів у рядках коду.

**Чим програма відрізняється від алгоритму?**

Алгоритм - це покроковий простий план дій, а програма - це такий самий план, але записаний кодом для комп'ютера.

**Навіщо потрібні мови програмування, якщо процесор їх усе одно не розуміє?**

Бо комп'ютер може розуміти тільки нулі та одиниці, а людині складно буде так писати, для цього і придумали мови програмування. І коли ми пишемо словами програма сама конвертує це в машиний код.

**Чи може комп'ютер зробити щось, чого йому не казали?**

Ні, не може, це може статись тільки при помилці програміста, а не за ініциативою комп'ютера.

**Чи є рецепт борщу алгоритмом?**

Це є алгоритмом тільки для людини, для комп'ютера він буде не точний, бо деякі фрази наприклад "посолити на смак" він зрозуміти не зможе.

**Опишіть, як зав'язати шнурки, для того, хто ніколи їх не бачив.**

Потрібрно взяти та перехрести дві мотузки, продінти один кінець знизу й затягни.
Зроби з кожної мотузки по петлі.
Перехрестити ці петлі між собою, продіти одне в отвір знизу та затягти.

**Програма правильно порахувала всі приклади з дошки. Чи Це доводить, що вона працює?**

Не доводить, бо вона порахувала приклади які тільки було на дошці, а на інших може не спрацювати. Наприклад при діленні на нуль або на від'ємнимх числах.
